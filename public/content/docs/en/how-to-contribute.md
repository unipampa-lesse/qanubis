# How to Contribute
We welcome contributions from the community to help improve QAnubis! Whether you're reporting bugs, suggesting new features, or submitting code changes, your input is valuable to us.

## Ways to Contribute
- **Report Issues**: If you encounter any bugs or issues while using QAnubis, please report them on our [GitHub Issues page](https://github.com/unipampa-lesse/qanubis/issues).
- **Suggest Features**: Have an idea for a new feature? Let us know by opening a feature request on our [GitHub Issues page](https://github.com/unipampa-lesse/qanubis/issues).
- **Submit Code**: If you'd like to contribute code, please fork the repository, make your changes, and submit a pull request. Be sure to follow our [contribution guidelines](/docs/contribution-guidelines).
- **Improve Documentation**: Help us enhance our documentation by suggesting edits or additions. You can do this by submitting a pull request to our wiki repository.
