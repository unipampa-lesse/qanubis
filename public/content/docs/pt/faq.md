# Perguntas Frequentes (FAQ)

Bem-vindo à seção de FAQ do QAnubis! Aqui respondemos as dúvidas mais comuns dos usuários.

## Perguntas Gerais

1. **O que é o QAnubis?**
   O QAnubis é uma ferramenta CAQDAS (Software de Análise Qualitativa de Dados Assistida por Computador) projetada para facilitar a pesquisa e a análise qualitativa.
