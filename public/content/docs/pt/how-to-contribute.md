# Como Contribuir

Somos muito bem-vindos a contribuições da comunidade para melhorar o QAnubis! Seja reportando bugs, sugerindo novas funcionalidades ou enviando código, sua participação é valiosa.

## Formas de Contribuir

- **Reportar Problemas**: Se encontrar algum bug, reporte na nossa [página de Issues no GitHub](https://github.com/unipampa-lesse/qanubis/issues).
- **Sugerir Funcionalidades**: Tem uma ideia? Abra um feature request na nossa [página de Issues](https://github.com/unipampa-lesse/qanubis/issues).
- **Enviar Código**: Faça um fork do repositório, implemente suas alterações e abra um pull request. Siga nosso [guia de contribuição](/docs/contribution-guidelines).
- **Melhorar a Documentação**: Ajude-nos a aprimorar a documentação sugerindo edições ou adições via pull request.
